
# TaskFlow - Gerenciador de Tarefas Web

## Sobre o projeto

O TaskFlow é uma aplicação web desenvolvida para auxiliar no gerenciamento e na organização de tarefas pessoais.

O sistema permite cadastrar atividades, acompanhar seu andamento em um quadro Kanban, editar e excluir tarefas, além de consultar indicadores de produtividade.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript puro, com armazenamento local por meio do localStorage.

## Funcionalidades

- Dashboard com indicadores de produtividade.
- Cadastro de tarefas.
- Edição de tarefas.
- Exclusão de tarefas.
- Definição de prioridade: baixa, média e alta.
- Definição de prazo para as atividades.
- Quadro Kanban com três etapas:
  - A Fazer
  - Em Andamento
  - Concluídas
- Alteração de status das tarefas.
- Pesquisa pelo título.
- Filtro por prioridade.
- Filtro por status.
- Limpeza dos filtros.
- Salvamento automático utilizando localStorage.
- Interface responsiva para diferentes tamanhos de tela.
- Tarefas demonstrativas na primeira abertura.

## Como executar o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no computador.
3. Localize o arquivo index.html.
4. Abra o arquivo em qualquer navegador moderno.
5. A aplicação estará pronta para utilização.

Não é necessário instalar banco de dados, servidor ou dependências externas.

## Armazenamento de dados

O TaskFlow utiliza o localStorage do navegador para armazenar as tarefas.

Os dados permanecem salvos mesmo depois de atualizar ou fechar a página, desde que o armazenamento do navegador não seja apagado.
